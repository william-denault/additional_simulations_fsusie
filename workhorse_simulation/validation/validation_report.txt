Validation of the residual-covariance comparison, 10 November 2026

Configuration: 100 candidate SNPs before monomorphic-column removal; 100
individuals; 60 positions; PVE 20%; true causal count 1 or 2; 50 replicates
per condition. Fitting limit remains 10 for all methods.

Seven methods: fSuSiE with standardize_Y=TRUE, plus diagonal, canonical and
mash mvSuSiE priors, each with estimate_residual_variance FALSE and TRUE.
Both members of each mvSuSiE pair use residual_variance=NULL and independent
copies of the same initial effect prior. No generating covariance is passed.

PASS: generation, causal assignment, expected PVE, GP covariance, zero-CS
handling, simulation-wise coverage, causal-SNP capture, disjoint two-worker
partition (400 datasets), checkpoint save/reuse and configuration mismatch
rejection.

PASS: actual seven-method fits on smooth/IID data with L=1 and step/GP data
with L=2. All 14 fits succeeded and reported convergence. All PIPs were
finite. Independently recomputed CS coverage and power agree with the stored
metrics. Fixed covariance variants retained cov(Y) to numerical precision
(relative differences below 6e-17); updated variants changed it.

PASS: restart reused both saved validation datasets without fitting again.
PDF/PNG output was generated and the seven-method CS-power layout inspected.
These two datasets are execution checks, not a performance study.

The installed mvsusieR 0.3.0 initialization was inspected directly:
set_mvsusie_residual_variance initializes an unspecified covariance to cov(Y)
for complete multivariate data (with regularization if not positive definite).

The prior two RStudio simulation workers were stopped. The 65 completed old
checkpoints remain in results/workhorse_50_T60_PVE20. The new full run ID is
workhorse_50_P100_L12_T60_RV; it has not been launched. Previous source files
are archived under archive/before_P100_L12_RV.

Packages: fsusieR 0.3.59; mvsusieR 0.3.0; susieR 0.16.6; mashr 0.2.79.
